# 用語集（夜をまたぐ売買でよく出る言葉）

| 用語 | 意味 |
|---|---|
| 寄り（寄付） | その日最初についた値段。前場は9:00から |
| 引け（大引け） | その日最後についた値段。東証の現物は15:30まで（2024年11月から） |
| 引成（ひけなり） | 引けの値段で売買する成行注文 |
| オーバーナイト | ポジションを持ったまま翌日にまたぐこと |
| ギャップアップ / ダウン | 翌朝の寄りが前日終値より高く / 安く始まること |
| 窓（まど） | ギャップでチャートにできた空白 |
| PTS | 証券取引所の外で売買できる私設取引システム。夜間も取引でき、翌朝の気配の目安になる |
| 日経平均先物（夜間） | 日中が終わったあとも夕方〜翌朝まで取引される。翌朝の地合いの目安 |
| 特別気配 | 注文が偏って値段がつかないとき、気配値を段階的に動かす状態 |
| 地合い（じあい） | 市場全体の雰囲気・方向性 |
| 適時開示（TDnet） | 企業が出す公式発表。15:00以降に出る決算や材料で翌朝が大きく動くことがある |
| 米国市場の影響 | 日本の夜に米国株が動くので、その結果が翌朝の寄りに反映されやすい |

> 気になった言葉はここに追加していきます。
