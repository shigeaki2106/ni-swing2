## ひとことで言うと

**失敗は隠さず、分類して、原因をさかのぼり、記録して次に活かす。** 防げる「悪い失敗」は減らし、成長につながる「よい失敗」は小さく積み重ねる。

## Chapter 1　失敗の捉え方を見直す

- **失敗の定義**：人が関わった行為で、望ましくない・予期しない結果が出ること（自然災害そのものは失敗ではない）
- 失敗を怖がって何もしない人も、失敗を気にせず突き進む人も、どちらも成長しない
- 小さな失敗を避け続けると、のちの大きな失敗の準備をしていることになる
- 失敗は「体験的知識」を得るチャンス。忘れようとすると、次にもっと大きな失敗をする
- 自分で失敗できないときは、**他人の失敗を自分事としてリアルに想像する（仮想失敗体験）**だけでも効果がある
- 失敗＝能力がない、ではない。挑戦しない人は失敗もしない
- 成功話は個別の事情に左右されるが、失敗話は原因が共通しやすく、教材として優れている

## Chapter 2　失敗を分類し分析する

### よい失敗と悪い失敗
| | よい失敗 | 悪い失敗 |
|---|---|---|
| 中身 | 意欲的に挑戦していて、未知のことに出会って起きた失敗 | 手抜き・不注意・ケアレスミスなど、本来防げた失敗 |
| 規模 | 周りでカバーできる程度 | 周りに大きなダメージを与える |
| 学び | 次に活かせる | 学びがなく、繰り返す |

世の中の失敗の大部分は「悪い失敗」。

### 失敗の原因を整理する道具
- **階層性**：原因は「個人（不注意・誤判断）→ 組織 → 行政・社会」と積み重なっている。上の層ほど深刻
- **逆演算**：結果から一つずつ前の出来事をさかのぼって、原因にたどり着く
- **失敗まんだら（原因の10分類）**

| 誰の責任か | 原因 |
|---|---|
| 誰の責任でもない | ① 未知 |
| 個人 | ② 無知　③ 不注意　④ 手順の不遵守　⑤ 誤判断　⑥ 調査・検討の不足 |
| どちらとも言えない | ⑦ 制約条件の変化（時間とともに環境が変わった） |
| 組織 | ⑧ 企画不良　⑨ 価値観不良　⑩ 組織運営不良 |

### 失敗を記録する6項目
1. **事象**：何が起きたか
2. **経過**：そこに至るまでの流れ
3. **原因**：自分なりの推定でよい（主観にヒントがある）
4. **対処**：そのとき何をしたか
5. **総括**：全体のまとめ
6. **知識化**：次に使える教訓だけを抜き出す

### 失敗の性質
- **ハインリッヒの法則**：重大事故1件の裏に、軽い事故29件、ヒヤリ・ハット300件
- 失敗の芽はカビのように育つ（発生 → 萌芽 → 顕在化 → 破裂）。萌芽の段階で手を打つ
- 失敗情報は**隠れたがる・単純化したがる・すり替わりたがる**
- 外から見るだけでは抜けが出る。**現地・現物・現人（3つの現）**で内側から見る

## Chapter 3　失敗を創造につなげる

- 失敗と創造は紙の表と裏。失敗から得た知識が、新しいアイデアの種になる
- 他人の成功例をそのまま真似ても通用しない。試行錯誤で自分のやり方を見つける
- 創造は「完成形から逆にたどる」思考で進むことが多い（逆演算と同じ）
- **創造的思考の4ステップ**
  1. 孤立分散仮説の生成：アイデアの種をばらばらに出す
  2. 仮説立証：種同士をつないで、始点から終点まで筋道を作る
  3. 具体化：筋道に肉付けする（細かすぎる部分はまだ決めない）
  4. 仮想演習：いろいろな条件でシミュレーションして、無理・無駄・矛盾を削る
- アイデアを詰め込みすぎない。行き詰まった試作品には執着せず、作り直す
- 計画には「時間とともに条件が変わる」ことを最初から入れておく
- 挑戦の成功率は低い（千三つ）。要素を一つずつ確実にして、成功確率を上げていく

## Chapter 4　創造的思考を鍛える

- **思いつきノート**：A4の紙に手書き。1テーマを4ページで掘り下げる
  - 1ページ目：思いついたことを全部書く（動機と背景も添える）
  - 2ページ目：つなげて筋道を作る（仮説立証）→ 本当の課題が見える
  - 3ページ目：肉付けする（具体化）。否定的にならない
  - 4ページ目：失敗やアクシデントを頭の中でわざと起こして、磨く（仮想演習）
  - 各ページに表題と日付を書く
- 完成に近づいたら、**信頼できる第三者に批評してもらう**。途中で言い返さず最後まで聞く
- **思考展開図**：目的 → 課題 → 課題要素（抽象）→ 解決策 → 具体案 → 全体計画（具体）と分解・統合して、抜け漏れを見つける

## Chapter 5　組織に活かす失敗学

- リーダーが安全に本気なら、事故は3分の1になる
- **責任追及より先に原因究明**。犯人探しを始めると、本当の原因が隠れる
- 減点主義の組織では、誰も挑戦しなくなる
- 失敗情報は、客観的なデータより**当事者の主観（そのとき何を感じ、どう考えたか）**のほうが役に立つ
- 表に出ていない失敗のリスクは「含み損」として扱う
- マニュアルは「やること」、べからず集は「やってはいけないこと」しか教えない。**失敗知識集（どう失敗し、なぜ失敗し、どう避けるか）**が地図になる
- 組織は約30年、社会は約60年で失敗を忘れる。記録して引き継ぐ
- 中途半端な知識は失敗の種。常に「**何のために**」を問い続ける（目標の数字が目的にすり替わる）
- 「想定外」は言い訳にならない。想定外は「その他」として別ルートで扱う
- **マニュアルは守るためにあり、変えるためにもある**。ただし勝手に破らず、全体を見直してから変える
- 本当のベテランは経験に新しい知識を足し続ける。偽ベテランは経験を過信する
- 真面目な人ほど、小さなトラブルのあと細かいことに気を取られ、一番大事なことを見落とす

## 夜討ち朝駆けに当てはめると

本の考え方を、いまのデイトレの記録に重ねてみたメモです。

| 本の考え方 | 夜討ち朝駆けでは |
|---|---|
| よい失敗／悪い失敗 | ルールどおりに入って損切り → **よい失敗**（手法の検証データになる）。寄り成行で飛びついた・損切りが遅れた → **悪い失敗** |
| 失敗まんだら | 損切りの滑り＝⑦制約条件の変化（板が薄い）、注文入力に時間がかかった＝④手順・⑥準備不足、Jevの誤分類＝② 無知／⑥ 調査不足、など原因の棚に分けられる |
| 6項目の記録 | 日次メモの「結果・気づき・宿題」を、事象→経過→原因→対処→総括→知識化に分けると、あとで集計しやすい |
| ヒヤリ・ハット | 「11:00の手仕舞いが8分遅れた」「スリープで画面が止まった」は、まだ損になっていないヒヤリ・ハット。放置すると大きな損につながる |
| 見送りも記録する | 見送った銘柄のその後を追うのは、他人の失敗から学ぶ「仮想失敗体験」と同じ発想 |
| マニュアルは変えるためにある | 「ルール変更は実弾30回のあと」と決めているのは、本の「勝手に破らず、全体を見直してから変える」と一致 |
| 「何のために」 | 目的は「手法に優位性があるかを確かめる」こと。実弾回数を増やすことや勝率を上げることが目的にすり替わらないようにする |
| 真面目ゆえの事故 | 小さなミスのあと細部ばかり気にすると、損切りという一番大事なことが遅れる |
| 想定外は「その他」へ | 特別気配で寄らない、板が気配を表示しない、などは「その他」として対応手順を別に決めておく |
