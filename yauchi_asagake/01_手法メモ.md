# 夜討ち朝駆け 手法メモ

> 出典：Googleドライブ「デイトレ記録」スプレッドシート（使い方・トレード記録・日次メモ）から整理（2026-11-19時点）。
> 「要確認」と書いた部分は、記録から読み取れなかったところです。

## ひとことで言うと

**夜に材料を見つけ、朝に駆ける。前場で完結するデイトレ。**

- 夜：前日15:00以降に出た好材料の適時開示から、候補を準備する
- 朝：寄り前の気配と、寄り後の値動き（3条件）を見て、入るかを決める
- 決済は前場のうち（11:00に手仕舞い）。**持ち越しはしない**

※最初に私が想像した「引けで買って翌朝売る」手法とは別物でした。

## Step1〜2：事前チェック（除外の条件）

次のどれかに当てはまったら、朝の段階で**除外**。

- 前日の売買代金が **2,000万円未満**（流動性不足）
- 事前5日の騰落率が **+10%以上**（材料が織り込み済みの可能性）
- 株価が **300円未満**
- 損切り幅から計算した株数が **100株未満**
- 100株でも **資金を超える**
- 同じ会社から **悪材料が同時に出ている**（増資・売出しなど、材料が混在）
- 名証のみの上場

## Step3：寄り前（8:58の気配）

| 気配の前日比 | 判定 |
|---|---|
| **+2%以上** | ◎本命 → Step4へ |
| 0〜+2% | ×見送り |
| マイナス | ×見送り |

- 特別気配で寄らない銘柄は追わない
- **寄り成行で飛びつかない**（ルール違反扱い）

## Step5：決済

| 項目 | ルール |
|---|---|
| 損切り | **ATR14 × 0.5** を損切り幅にする（逆指値） |
| 利確目標 | 損切り幅の **2倍**（+2R） |
| タイムストップ | **11:00** で残りを手仕舞い |
| 持ち越し | しない |

## 資金管理（2026/10/9から）

| 項目 | 金額 |
|---|---|
| 資金 | 100万円 |
| 1回の許容損失 | 1万円 |
| 1日の損失上限 | 2万円 |
| 株数 | 許容損失 ÷ 損切り幅（100株単位） |

（10/8までは資金50万円・許容損失5,000円）

## 成績の見方

- **R倍数** ＝ 損益 ÷（損切り幅 × 株数）。損切りどおりなら −1R、利確どおりなら +2R
- 利確+2R・損切り−1Rなので、**勝率33%で損益トントン**（手数料・滑りを除く）
- **実弾30回**で手法を評価する。いまのバージョンが「案5」

## これまでの日次メモから拾った学び

- 気配が本命（+2%以上）でも、寄りで崩れることがある
- 下げた日は、VWAPが戻りの壁になりやすい
- 月次の材料は、初動のあと続きにくい
- 好材料の特別気配は、時間とともに切り上がって寄り天になりやすい（追わない）
- 決算で「改善」と判定されても、気配がマイナスなら大きく売られることがある → +2%未満見送りのルールで回避できた
- 値動きの大きい銘柄は、許容損失の範囲だと100株に届かない
- 板が薄い銘柄は、損切りの成行が滑る
- 注文の入力に時間がかかると、エントリーが遅れる → 注文カードで短縮
