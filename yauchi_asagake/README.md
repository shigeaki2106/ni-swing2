# 夜討ち朝駆け 勉強ノート

前場で完結するデイトレ手法「夜討ち朝駆け」を勉強・検証するためのフォルダです。
スイング用の自動分析システム（このリポジトリの他のファイル）とは別物です。

## フォルダの中身

| ファイル | 何を書くか |
|---|---|
| `01_手法メモ.md` | 夜討ち朝駆けのルール（Googleドライブの「デイトレ記録」から整理） |
| `02_用語集.md` | この手法でよく出てくる言葉 |
| `03_疑問メモ.md` | わからなかったこと・あとで調べること |
| `04_検証記録.md` | ルールを変えたときの結果比較 |
| `本の要約/` | 読んだ本の要約と、手法への当てはめ（`失敗学.md` など） |
| `日記/` | 1日1ファイルのトレード日記（`_テンプレート.md` をコピーして使う） |

## 使い方

1. `01_手法メモ.md` でルールを確認する（「要確認」の部分は教えてもらえれば埋めます）
2. 毎日のトレードを `日記/` に記録する
3. 疑問はその場で `03_疑問メモ.md` に書く → あとでまとめて調べる
4. 1〜2週間ごとに日記を見返して、勝ち負けの傾向を `04_検証記録.md` にまとめる

## 注意

このリポジトリが公開（Public）設定だと、日記の中身は誰でも見られます。
実際の金額や口座情報は書かないか、リポジトリを非公開（Private）にしてください。
